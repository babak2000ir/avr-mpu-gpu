Wiring:

| Signal    | MPU ATmega328P | GU ATmega328P |
| --------- | --------- | ---------- |
| MOSI      | PB3 / MOSI (D11, DIP pin 17) output | PB3 / MOSI (D11, DIP pin 17) input |
| MISO      | PB4 / MISO (D12, DIP pin 18) input  | PB4 / MISO (D12, DIP pin 18) output |
| SCK       | PB5 / SCK (D13, DIP pin 19) output  | PB5 / SCK (D13, DIP pin 19) input |
| CS        | PB2 / SS (D10, DIP pin 16) output   | PB2 / SS (D10, DIP pin 16) input |
| READY     | PD2 (D2, DIP pin 4) input | PD2 (D2, DIP pin 4) output |

Both AVRs are driven by a shared external 20 MHz clock line into `XTAL1`
(`PB6`, DIP pin 9). Only `XTAL1` is used; `XTAL2` (`PB7`, DIP pin 10) is left
free and usable as a GPIO on both chips. Do not use `PB6` as a GPIO on either
chip.
