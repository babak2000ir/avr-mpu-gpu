Wiring:

| Signal    | MPU       | GU         |
| --------- | --------- | ---------- |
| MOSI / DI | PA6       | PA6        |
| MISO / DO | PA5       | PA5        |
| SCK       | PA4       | PA4        |
| CS        | PA7       | PA7        |
| READY     | PB2 input | PB2 output |

`PB0` on both controllers is reserved for the external clock input and must
not be used or configured as a GPIO.
